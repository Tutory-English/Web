TOEFL Preparation Class

Program persiapan TOEFL yang dirancang secara terstruktur untuk membantu kamu mencapai skor target — baik untuk TOEFL iBT maupun TOEFL ITP. Setiap paket dimulai dengan pre-test untuk memetakan levelmu dan diakhiri dengan progress test untuk mengukur peningkatan.

Durasi

20 atau 40 Jam Sesi

Format Kelas

Privat 1-on-1

Pre-test & Progress Test

Untuk memetakan level awal dan mengukur peningkatan skor

TOEFL iBT

TOEFL iBT Preparation

Persiapan menyeluruh untuk TOEFL iBT mencakup semua empat skill: Reading, Listening, Speaking, dan Writing.

  • Strategi menjawab soal passage akademik
  • Teknik skimming, scanning, dan inferensi
  • Latihan tipe soal: vocabulary, sentence insertion, prose summary
  • Strategi note-taking untuk lecture dan conversation
  • Pemahaman main idea, detail, dan inference
  • Latihan soal lecture akademik dan diskusi kampus
  • Strategi Independent Task dan Integrated Task
  • Template respons untuk setiap tipe soal
  • Drilling dengan rekaman dan feedback detail
  • Strategi Integrated Writing dan Independent Writing
  • Teknik sintesis informasi dari reading + listening
  • Koreksi dan feedback esai oleh tutor
TOEFL ITP

TOEFL ITP Preparation

Persiapan terfokus untuk TOEFL ITP mencakup tiga bagian utama: Listening Comprehension, Structure and Written Expression, dan Reading Comprehension.

  • Pemahaman Short Conversation, Long Conversation, dan Mini Talk
  • Strategi menangkap main idea dan detail
  • Latihan soal dengan feedback dan pembahasan
  • Penguasaan pola kalimat dan tata bahasa akademik
  • Strategi Structure Completion dan Error Recognition
  • Drilling soal grammar intensif
  • Teknik membaca passage akademik dengan efisien
  • Strategi menjawab soal inference, vocabulary in context, main idea
  • Latihan soal passage dengan pembahasan mendalam
